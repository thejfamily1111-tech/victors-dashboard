# Active-market 17-team dashboard

The existing dashboard now displays the original six teams plus eleven archived report winners, with active market direction, data coverage, source timestamps and entry sizing. It continues to require the existing passcode and read-only telemetry credentials. No broker orders are executed by dashboard.py.

The updated Mac engine must be installed and started before the added teams send activity. Old six-team telemetry is explicitly identified; missing teams show disconnected.
